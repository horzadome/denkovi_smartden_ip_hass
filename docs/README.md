# Project documents

This directory holds the project documents. The file name gives the kind of document:

- `TRIAGE_<name>.md` records the triage of one issue. It holds the cause and the
  classification.
- `FEATURE_<name>.md` describes one feature, planned or built.
- `TEST_<name>.md` holds a test procedure or a test result.
- `LOCALDEV.md` holds the rules for this machine.

When you finish the work and every check passes, delete the `TRIAGE_` document and the
`FEATURE_` document.

A `TRIAGE_` document records the situation at the time of the work. A command in its Evidence
section names the tools of that time. The rules in force are the current ones.

Write research notes into `docs/research/`.
